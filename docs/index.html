Setup

Up and running in seconds.

No command line, no root passwords, no complicated config files.

01 DRAG & DROP
Bongo.dmg
Applications

Download & Drag

Download Bongo DMG (Apple Silicon or Intel), open it, and drag Bongo.app into your Applications folder.

02 ZERO CONFIG
Auto-Registers Keyboard Service

Launch Once

Open Bongo from Applications. It registers the input method service with macOS automatically without requiring administrator rights.

03 INSTANT SWITCH
🌐 fn or ⌃ Ctrl + Space

Enable & Switch

In System Settings → Keyboard → Input Sources, click + and add Bongo (under Bengali). Switch anytime with Globe / fn or Ctrl + Space!

01 INSTALL PACKAGE
$ sudo apt install ./bongo.deb

Download or Install

Download bongo_1.0.1_amd64.deb (for standard PC) or bongo_1.0.1_arm64.deb (for ARM64) and install with sudo apt install ./bongo_1.0.1_amd64.deb, or use our one-line terminal installer.

02 INPUT METHOD
IBus Framework · Bengali (Bongo)

Enable Input Source

In Settings → Keyboard → Input Sources, click +, search for Bengali (Bongo), and add it.

03 KEYBOARD HOTKEY
⌘ Super + Space

Switch & Configure

Press Super + Space or Ctrl + Space to type in Bangla. Launch bongo-settings anytime for the layout cheatsheet and font configuration.

01 RUN INSTALLER
Bongo-Setup.exe

Download & Run

Download Bongo-Setup-1.0.1.exe (or .msi for enterprise, or standalone .zip for portable use) and click Install. No external dependencies required.

02 SYSTEM TRAY
Taskbar Notification Area · Ready

Starts in Background

Bongo runs in your taskbar system tray. Right-click the icon anytime to open Settings, change candidate fonts, or inspect the phonetic cheatsheet.

03 INSTANT TOGGLE
F12

Press F12 Anywhere

Press F12 in any application (Word, Notepad, Chrome, VS Code) to switch instantly between English and Bangla mode.

01 INSTALL APK
Bongo-1.0.0-android.apk

Download & Install

Download Bongo-1.0.0-android.apk directly on your phone and open it to install. Allow unknown apps installation if prompted.

02 ENABLE IME
Bongo Settings · 2-Step Setup

Enable in Settings

Open the Bongo app from your home screen. Tap Enable Bongo Keyboard and toggle it ON in Android System Settings.

03 START TYPING
Bongo Keyboard · Active

Select & Type

Tap Select Bongo Keyboard to set it as your active keyboard. Open WhatsApp, Messenger, or Chrome and start typing phonetically in Bangla!

Answers

Frequently Asked Questions

Clear information regarding multi-platform support, security, compatibility, and day-to-day use.

Which operating systems and devices does Bongo support?

Bongo is natively available across all four major platforms: macOS (Apple Silicon M1–M4 and Intel x86_64 via native InputMethodKit & Universal 2 DMG), Windows (Windows 10 & 11 with live floating Candidate HUD, .exe and .msi installers), Linux (Ubuntu, Debian, Mint, Fedora, Arch via native IBus engine), and Android (Android 8.0 through 15+ standalone signed APK with Ridmik layout & voice typing).

How does phonetic typing work in Bongo?

Bongo uses intuitive Avro Phonetic typing: write Bengali sounds phonetically using standard English letters (e.g. typing ami produces আমি, bangla produces বাংলা, dhonnobad produces ধন্যবাদ). Powered by an embedded Rust phonetic engine with a 150,000+ word dictionary, compound word fixes, and instant autocorrect.

How does Bongo work on Windows, and does it show suggestion candidates?

Yes! On Windows, Bongo runs as a low-level background service featuring a live floating Candidate HUD window right below your typing cursor in any application (Word, Chrome, Notepad, IDEs). You can cycle suggestions with Down Arrow or Tab, return with Up Arrow, select directly with 1–9, or click candidates with your mouse without losing application focus. Press F12 or Ctrl + Space to toggle Bangla mode anytime.

What features does Bongo offer on Android?

Bongo for Android is an on-device keyboard featuring a familiar layout inspired by Ridmik. It features instant layout switching between English ABC, Avro Phonetic, and Probhat using the Spacebar or Globe key, integrated voice typing with native speech recognition, a built-in emoji and symbol tab picker, number row, haptic feedback, and runs 100% offline on your device.

How do I switch quickly between English and Bangla across different platforms?

Switching is effortless on every platform: macOS: tap the Globe (fn) key or press Control + Space; Windows: press F12 or Control + Space; Linux: press Super + Space or Control + Space; Android: tap the Globe (🌐) key or hold/swipe the Spacebar.

Does Bongo track what I type or require internet access?

Never. Bongo is strictly offline and privacy-first across all four platforms (macOS, Windows, Linux, and Android). It has zero network permissions, zero cloud servers, zero keystroke logging, and zero telemetry. All transliteration, dictionary lookup, and candidate suggestions happen 100% locally on your machine or phone.

Can I change font styles or customize candidate preview settings?

Yes! On macOS, Windows, and Linux, Bongo includes a native Settings application where you can customize candidate font family (such as Noto Sans Bengali, Kalpurush, SolaimanLipi), adjust font size, change default switch shortcuts, and customize UI themes.

Is Bongo completely free and open source?

Yes. Bongo is 100% free with no ads, tracking, subscriptions, or paywalls. The complete project is open source under the Mozilla Public License 2.0 (MPL-2.0) on GitHub.
